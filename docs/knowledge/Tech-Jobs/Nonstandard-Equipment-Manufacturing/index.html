非标制造行业（Custom/Nonstandard Equipment Manufacturing）

非标制造行业（Custom/Nonstandard Equipment Manufacturing）常见岗位，便于中英文场合交流与简历、岗位说明书使用。

1. 项目工程师 / 项目负责人​

  • 英文名：Project Engineer / Project Responsible
  • 英文缩写：PE / PR
  • 主要职责：负责项目整体技术方案设计与落地，项目进度跟进，统筹协作与客户沟通。
  • 代表场合：定制化设备项目管理、跨部门技术协调。
  • 典型问题：技术方案如何满足客户需求？项目进度延误如何协调？技术变更如何落地？

2. 机械设计工程师​

  • 英文名：Mechanical Design Engineer
  • 英文缩写：MDE
  • 主要职责：机械结构与零部件设计、工程图出图，装配可行性分析与改进。
  • 代表场合：设备研发设计、定制装备结构优化。
  • 典型问题：机械结构如何减少干涉？设计图纸能否快速通过审核？装配过程如何规避难点？

3. 电气工程师​

  • 英文名：Electrical Engineer
  • 英文缩写：EE
  • 主要职责：电气方案设计、电控系统开发，PLC编程与电气调试。
  • 代表场合：自动化设备电气设计、控制系统实施。
  • 典型问题：PLC程序调试不顺利如何排查？电气系统短路或失灵怎么办？电气布线设计如何确认合理？

4. 自动化/软件工程师​

  • 英文名：Automation Engineer / Software Engineer
  • 英文缩写：AE / SE
  • 主要职责：自动化控制系统与软件开发（PLC/HMI/运动控制/机视觉），系统程序调试与优化。
  • 代表场合：设备自动化集成、生产线智能化开发。
  • 典型问题：自动化程序与现场实际不吻合怎么办？系统升级时如何保证兼容性？设备运行速度怎么优化？

5. 工艺工程师​

  • 英文名：Process Engineer
  • 英文缩写：PE
  • 主要职责：生产工艺流程制定与优化，工艺过程管控及现场指导。
  • 代表场合：产品设计向制造的工艺转化，生产线工艺流程优化。
  • 典型问题：产品工艺流程怎么确定？生产过程为何出现异常？怎样改善制程效率？

6. 结构工程师​

  • 英文名：Structural Engineer
  • 英文缩写：SE
  • 主要职责：设备结构件和力学分析，确保安全、可装配与可靠性。
  • 代表场合：大型非标设备结构设计与分析。
  • 典型问题：结构强度不达预期怎么办？设备振动如何控制？结构件选材怎么综合考虑？

7. 采购工程师 / 供应链专员​

  • 英文名：Procurement Engineer / Supply Chain Specialist
  • 英文缩写：PE / SCS
  • 主要职责：零部件采购、供应商开发、成本与交期管理。
  • 代表场合：项目采购管理、物料跟进与成本控制。
  • 典型问题：关键物料如何确保及时供应？采购成本如何优化？供应商质量不达标如何处理？

8. 质量工程师​

  • 英文名：Quality Engineer
  • 英文缩写：QE
  • 主要职责：来料、生产、成品的质量管控，过程检验及客户验收技术对接。
  • 代表场合：产品生产、客户验收、工艺改进等环节。
  • 典型问题：生产过程频发质量异常怎样根因定位？客户验收不通过如何应对？来料检验标准如何制订？

9. 生产主管 / 车间主任​

  • 英文名：Production Supervisor / Workshop Manager
  • 英文缩写：PS / WM
  • 主要职责：生产计划与组织、现场安全管理、工人分工协作。
  • 代表场合：车间现场生产、人员管理、工序调度。
  • 典型问题：生产进度滞后怎么调整？人员安排如何高效？现场安全隐患如何排查整改？

10. 工艺员 / 技术员​

  • 英文名：Technician
  • 英文缩写：Tech
  • 主要职责：协助工程师完成生产、调试、装配与检修。
  • 代表场合：设备装配、技术实施、日常维护。
  • 典型问题：具体装配流程难点如何解决？设备调试遇障碍怎么办？技术文件如何归档整理？

11. 售后技术工程师​

  • 英文名：After-sales Support Engineer
  • 英文缩写：ASE
  • 主要职责：设备安装、运行维护、客户技术培训及远程或现场故障排除。
  • 代表场合：客户现场支持、交付后技术服务。
  • 典型问题：设备故障客户无法自行排查怎么办？售后服务响应速度如何保证？客户使用技巧怎么培训？

12. 项目经理​

  • 英文名：Project Manager
  • 英文缩写：PM
  • 主要职责：项目全生命周期管理，跨部门协调，项目进度与成本控制，客户沟通与团队管理。
  • 代表场合：项目立项、实施、交付、归档全过程。
  • 典型问题：项目延期如何处理与协调？项目成员分工如何优化？客户变更需求如何应对？

13. 销售/业务工程师​

  • 英文名：Sales Engineer / Business Engineer
  • 英文缩写：SE / BE
  • 主要职责：需求挖掘、业务开发、技术方案演示、客户谈判与订单转化。
  • 代表场合：客户拜访、技术交流、市场推广。
  • 典型问题：客户技术需求如何快速转化？竞标方案如何优化？商务谈判技巧怎样提升？

14. 研发工程师​

  • 英文名：R&D Engineer（Research and Development Engineer）
  • 英文缩写：RDE
  • 主要职责：新技术、新产品持续研发、工艺创新与行业标准突破。
  • 代表场合：技术预研、产品升级、技术攻关。
  • 典型问题：新技术方案如何验证？研发周期为何延长？创新点怎么转化为工程制造？

15. 文控/技术文员​

  • 英文名：Document Controller / Technical Assistant
  • 英文缩写：DC / TA
  • 主要职责：技术资料归档、文档整理、进度与流程汇报。
  • 代表场合：项目技术文件、工程档案管理、报告制作。
  • 典型问题：技术资料如何规范管理？文件归档如何防止丢失？项目技术文档如何催交？
